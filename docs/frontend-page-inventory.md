# Frontend page inventory

## Public and reference pages

`index.html`, `login.html`, `signup.html`, `forgot-password.html`, `404.html`, `design-system.html`, and `layout-test.html`. Sign Up supports all four role profiles with frontend-only approval-code rules.

## Admin

Dashboard, users, vehicles, drivers, mileage logs, service types, maintenance, reports, reminders, settings, and read-only audit logs.

## Manager

Dashboard, vehicle and driver views, assignments, schedules, reports, and reminders.

## Mechanic

Dashboard, maintenance tasks, service history, and notifications.

## Driver

Dashboard, mileage, assigned vehicle, maintenance reminders, and notifications.

## Shared

Profile, notifications, and search. Shared pages use the active demo session and are available to every role.
