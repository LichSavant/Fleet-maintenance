# Archived ForgeFleet static prototype

This directory contains the original HTML, CSS, and browser-JavaScript ForgeFleet prototype. It is preserved for historical and visual reference only.

The active application is the React, Vite, and TypeScript project in [`../frontend/`](../frontend/). Do not add new product features to this archived implementation.

If the prototype must be reviewed, serve this directory through a local HTTP server so its fetched HTML partials can load. Its browser-storage authentication and authorization are demonstrations only and must not be treated as secure.
